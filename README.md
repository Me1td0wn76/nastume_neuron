# nastume_neuron — NumPy だけで作る、小さな文豪 AI

青空文庫の夏目漱石（ほか文豪）の作品を読み込んで学習し、
**入力した文章の続きを、文豪風に書く**小さな生成 AI です。

PyTorch などの深層学習フレームワークは使わず、**NumPy だけ**で
GPT と同じ仕組み（Transformer）を実装しています。逆伝播（勾配の計算）も手書きです。

```
あなた> 吾輩は猫である。名前はまだ無い。
夏目漱石AI> 吾輩は猫である。名前はまだ無い。……（続きを AI が書く）
```

## しくみ（ざっくり）

このモデルがやっていることは、**「ここまでの文章の、次の1文字を当てる」** だけです。
それを1文字ずつくり返すと文章になります。

```
文字ID列 ─→ 埋め込み（文字ベクトル + 位置ベクトル + 作家ベクトル）
         ─→ Transformer ブロック × n_layer
               ├ 自己注意機構: 前の文字のどれに注目するかを学ぶ
               └ MLP:         各文字のベクトルを変換する
         ─→ 次の文字の確率（約3,600種類の文字それぞれについて）
```

学習では、漱石の文章から切り出した文字列を見せて「次の文字」を予測させ、
外れた分（損失）が小さくなるように重みを少しずつ直していきます。

## 準備

[uv](https://docs.astral.sh/uv/) を使います。

```sh
uv sync
```

> **必ず `uv run` で実行してください。** 
> 行列計算ライブラリを使っており、`uv` が入れる NumPy より約40倍遅いです。

## 使い方（4ステップ）

### 1. 青空文庫からダウンロード

```sh
uv run python download.py            # 夏目漱石の84作品（約2分）
```

`data/raw/夏目漱石/` に保存されます。サーバーに負荷をかけないよう、1作品ごとに1秒待ちます。

### 2. 学習用データに変換

```sh
uv run python prepare.py
```

ルビ（`漢字《かんじ》`）や注記（`［＃…］`）、冒頭・末尾の説明文を取り除き、
1文字ずつ番号（ID）に変換します。整形後の本文は `data/processed/corpus_夏目漱石.txt` で確認できます。
漱石の場合、約330万文字・約3,600種類の文字になります。

### 3. 学習

```sh
uv run python train.py --preset tiny   # まず動作確認（約1分）
uv run python train.py                 # 本番（small、約1時間）
```

| プリセット | パラメータ数 | 学習時間の目安（このPC） | 用途 |
|---|---|---|---|
| `tiny`   | 約34万  | 約1分   | 動作確認 |
| `small`  | 約250万 | 約1時間 | 標準 |
| `medium` | 約710万 | 約6時間 | 一晩かけて |

学習中は、損失（小さいほど良い）と、評価のたびに「吾輩は」から書かせた生成例が表示されます。
だんだん文章らしくなっていく様子を見られます。

- `Ctrl+C` で中断しても状態は保存されます。`uv run python train.py --resume` で続きから再開できます
- モデルは `checkpoints/<プリセット名>/` に保存されます
- `--n-layer 6 --n-embd 256` のように個別に設定を変えることもできます（`--help` で一覧）

### 4. 文章を生成（text to text）

```sh
uv run python generate.py                                  # 対話モード
uv run python generate.py --prompt "親譲りの無鉄砲で"       # 1回だけ
uv run python generate.py --ckpt checkpoints/small         # モデルを選ぶ
```

対話モードでは、書き出しの文章を入力すると続きを書きます。

| コマンド | 意味 |
|---|---|
| `/temp 0.6` | temperature。小さいほど無難な文、大きいほど冒険的な文になる（標準 0.8） |
| `/len 300` | 生成するおおよその文字数 |
| `/author 芥川竜之介` | 真似る作家を切り替える（複数の作家で学習したとき） |
| `/quit` | 終了 |

## 他の文豪でも学習する

作家ごとに「作家ベクトル」を学習するので、複数の作家をまとめて学習し、
生成時に誰の文体で書くかを選べます。

```sh
uv run python download.py 芥川竜之介 太宰治
uv run python prepare.py                  # data/raw/ にいる全員を使う
uv run python train.py --name bungo
uv run python generate.py --author 太宰治
```

作家名は青空文庫の表記で、姓と名を続けて書きます（例: `森鴎外`、`宮沢賢治`）。
標準では表記を揃えるため「新字新仮名」の作品だけを使います。旧仮名の作品も入れるなら `--all-kana` を付けます。
データが増えるほど学習には時間がかかります。

## 用語メモ

- **損失（loss）**: 予測の外れ具合。最初は約 8.2（= log 3651、全文字を当てずっぽうで選ぶのと同じ）から始まり、学習で下がっていく
- **困惑度（perplexity）**: exp(損失)。「次の文字の候補を、平均で何文字まで絞り込めているか」の目安
- **検証用データ**: 学習に使わずに取っておいた文章（各作品の末尾5%）。ここでの損失が下がっていれば、丸暗記ではなく文体を身につけている
- **temperature / top-k**: 生成時に、確率の高い文字をどれくらい優先するかの調整

## 次の一歩（改造のアイデア）

- **Dropout** を追加して、長く学習しても丸暗記しにくくする
- **BPE などのサブワード分割**にして、1トークンで複数文字を扱う
- **KV キャッシュ**で生成を速くする（今は毎回、文脈全体を計算し直している）
- 同じモデルを **PyTorch で書き直して**、自動微分と速度を比べてみる

## データについて

学習データは[青空文庫](https://www.aozora.gr.jp/)から取得しています。
著作権の切れた作品（作品著作権フラグ「なし」）だけを使います。
青空文庫はボランティアによって運営されているので、ダウンロードは必要な分だけにしましょう
（一度ダウンロードしたファイルは再取得しません）。
